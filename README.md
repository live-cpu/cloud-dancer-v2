## 🌤️ 소개

**Cloud Dancer**는 당신의 마음속 문장을 구름 위로 띄워,
그 결과 닮은 **디자이너와 아티스트**를 연결해주는 감성 추천 서비스입니다.

> *"지금 머릿속에 맴도는 문장을 짧게 적어보세요."*

당신이 적은 단어의 **결(texture)**을 분석하여,
비슷한 감성을 가진 작가와 — 그리고 반대 결로 균형을 잡아줄 작업들까지 추천합니다.

<br>

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎨 **감성 키워드 분석** | 입력한 문장에서 핵심 감정/이미지 키워드 추출 |
| 🔍 **아티스트 매칭** | 비슷한 결을 가진 디자이너/작가 검색 |
| ⚖️ **대비 추천** | 반대 결의 작업으로 균형감 있는 영감 제공 |
| ☁️ **몰입형 UI** | 구름에서 숲으로 이어지는 시각적 여정 |

<br>

## 🛠️ 기술 스택

- **Frontend**: React + Vite
- **Styling**: CSS (Custom Design System)
- **API**: Google Custom Search API
- **Hosting**: GitHub Pages + Render

<br>

## 🚀 로컬 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행

# 프로덕션 빌드
```
